1. Multi-Tenancy & Subscription Licensing Subsystem

Multi-tenancy enables complete tenant isolation where root companies manage branches / subsidiaries (organizations), each controlled by active subscription limits (organization_plans) and enabled features (organization_modules).

4. ZKTeco ADMS Biometrics & Shift Roster Subsystem

Hardware push-protocol attendance gateway ingesting real-time raw logs from physical ZKTeco biometric terminals (adms_devices), evaluated against scheduled shift rules (work_shifts, duty_rosters) to compute daily attendance (hrm_attendances).

5. User Authentication, Security & Audit Logs Subsystem

User identities (users) link to both company/organization tenants and HRM employee profiles, secured by login telemetry (user_login_attempts), historical password reuse tracking (password_histories), and immutable field-level audit trails (audit_logs).

6. Universal & HRM Dynamic Lookups Subsystem

Provides dual-tier dictionary lookups: system-wide universal metadata (global_lookup_groups, global_lookups) and tenant-scoped dynamic lists (hrm_lookup_groups, hrm_lookups) for Departments, Designations, Shift Types, Leave Classifications, and Relationships.

7. Leave Management, Quotas & Holiday Calendar Subsystem

Tracks annual holiday calendars (hrm_holidays), individual yearly leave quotas and remaining balances (hrm_leave_balances), multi-day leave approval workflows (hrm_leave_applications), and medical document attachments (hrm_leave_application_documents).
